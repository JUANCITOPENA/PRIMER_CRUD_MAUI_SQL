🌐 PASO 2.5: ACTIVAR CONEXIONES REMOTAS, CONFIGURAR TCP/IP 1433 Y REGLAS DE FIREWALL
⚠️ Requisito Indispensable para Conectar Celulares y Emuladores: Por motivos de seguridad predeterminada de Windows, SQL Server viene configurado de fábrica para rechazar conexiones remotas por red y escuchar en puertos dinámicos. Para que tu aplicación móvil en Android o Windows Machine se comunique con la base de datos, debes cumplir estrictamente estos 3 pasos:
  1. 1. Activar Conexiones Remotas en SSMS:
    En el Object Explorer, clic derecho en el nodo raíz del servidor → Properties → menú Connections → Asegúrate de que la casilla "Allow remote connections to this server" (Permitir conexiones remotas a este servidor) esté marcada → Clic en OK.
  2. 2. Habilitar Protocolo TCP/IP y Asignar Puerto Estático 1433 en Configuration Manager:
    • Presiona Win + R, escribe SQLServerManager16.msc (o SQLServerManager15.msc) y pulsa Enter.
    • En el panel izquierdo despliega SQL Server Network Configuration → haz clic en Protocols for SQLEXPRESS (o Protocols for MSSQLSERVER).
    • En el panel derecho haz clic derecho sobre TCP/IP → selecciona Enable → pulsa OK.
    • Haz doble clic sobre TCP/IP → ve a la pestaña IP Addresses.
    • Desplázate hasta el final de la lista hasta encontrar la sección IPAll:
      - En TCP Dynamic Ports: borra cualquier número y déjalo completamente en blanco.
      - En TCP Port: escribe exactamente 1433.
      - Haz clic en Apply y luego en OK.
  3. 3. Abrir Puertos en el Firewall de Windows y Activar SQL Server Browser:
    Ejecuta PowerShell como Administrador para abrir el puerto TCP 1433 (Motor de SQL), el puerto UDP 1434 (SQL Browser, necesario para que los dispositivos móviles resuelvan la instancia), activar el servicio SQL Browser y reiniciar el motor de base de datos.
PowerShell (Ejecutar como Administrador) - Reglas Firewall, SQL Browser y Reinicio 
# ==============================================================================
# SCRIPT DE CONFIGURACIÓN DE RED Y FIREWALL PARA SQL SERVER (PUERTO 1433 Y 1434)
# ==============================================================================

# 1. Crear Regla de Entrada en el Firewall para el Puerto TCP 1433 (Motor SQL Server)
New-NetFirewallRule -DisplayName "SQL Server Port 1433 TCP" `
    -Direction Inbound -LocalPort 1433 -Protocol TCP -Action Allow `
    -Description "Permite conexiones de clientes MAUI y Power BI al motor SQL Server"

# 2. Crear Regla de Entrada en el Firewall para el Puerto UDP 1433
New-NetFirewallRule -DisplayName "SQL Server Port 1433 UDP" `
    -Direction Inbound -LocalPort 1433 -Protocol UDP -Action Allow

# 3. Crear Regla de Entrada para el Puerto UDP 1434 (Servicio SQL Server Browser)
New-NetFirewallRule -DisplayName "SQL Server Browser Port 1434 UDP" `
    -Direction Inbound -LocalPort 1434 -Protocol UDP -Action Allow `
    -Description "Permite el descubrimiento de instancias nombradas de SQL Server en red local"

# 4. Habilitar y Configurar el Servicio SQL Server Browser en Inicio Automático
Set-Service -Name "SQLBrowser" -StartupType Automatic
Start-Service -Name "SQLBrowser"

# 5. Reiniciar el Servicio de SQL Server para que cargue la configuración TCP/IP
# Nota: Si tu instancia es Express, el servicio se llama 'MSSQL$SQLEXPRESS'. Si es por defecto, 'MSSQLSERVER'.
try {
    Restart-Service -Name "MSSQLSERVER" -Force -ErrorAction Stop
    Write-Host "✅ Servicio MSSQLSERVER reiniciado con éxito." -ForegroundColor Green
} catch {
    Restart-Service -Name "MSSQL`$SQLEXPRESS" -Force
    Write-Host "✅ Servicio MSSQL`$SQLEXPRESS reiniciado con éxito." -ForegroundColor Green
}

# 6. Mostrar la Dirección IPv4 Local de tu PC (Esta es la IP que usarás en tu celular)
Write-Host "`n📡 TUS DIRECCIONES IP LOCALES:" -ForegroundColor Yellow
ipconfig | findstr /i "IPv4"
📚 PASO 2.6: FUNDAMENTOS DE BASES DE DATOS RELACIONALES, TABLAS, CICLO CRUD Y VISTAS

Antes de ejecutar el script, comprende los fundamentos de ingeniería de datos aplicados en este proyecto:

1. ¿QUÉ ES UNA BASE DE DATOS Y SUS TABLAS?

Una Base de Datos Relacional (RDBMS) es un contenedor estructurado que garantiza la integridad, consistencia (principios ACID) y persistencia de la información en disco.

  • Tabla: Representa una entidad del negocio (ej. Productos). Se organiza en filas y columnas.
  • Columna (Campo): Atributo tipado con rigor: INT para enteros, NVARCHAR(N) para textos Unicode, DECIMAL(18,2) para importes monetarios.
  • Clave Primaria (Primary Key - PK): Identificador único e irrepetible de cada fila con auto-incremento (IDENTITY(1,1)).
  • Clave Foránea (Foreign Key - FK): Campo que enlaza un registro hijo con la clave primaria de su tabla padre (ej. Productos.CategoriaID → Categorias.CategoriaID con ON DELETE CASCADE).
2. EL CICLO CRUD Y SU EQUIVALENCIA T-SQL

CRUD representa las cuatro operaciones fundamentales sobre cualquier entidad de datos persistente:

  • C - Create (Crear): Se ejecuta con INSERT INTO para registrar nuevos elementos.
  • R - Read (Leer): Se ejecuta con SELECT para consultar, filtrar (WHERE) y ordenar (ORDER BY).
  • U - Update (Actualizar): Se ejecuta con UPDATE ... SET ... WHERE para modificar datos existentes con control de seguridad.
  • D - Delete (Eliminar): Se ejecuta con DELETE FROM ... WHERE para suprimir registros específicos de forma controlada.
3. ¿QUÉ ES UNA VISTA (VIEW) Y POR QUÉ ES CRUCIAL?

Una Vista (`VIEW`) es una consulta SQL pre-compilada guardada en el servidor que actúa como una tabla virtual. No duplica datos; une tablas mediante INNER JOIN y calcula indicadores en tiempo real (como ValorInventario = Precio * Stock y alertas de semáforo CASE WHEN Stock = 0 THEN 'Agotado'). Permite a la app móvil y a Power BI consultar KPIs analíticos con un simple SELECT * FROM vw_ReporteInventario.

-- =============================================================================
-- FASE 4: VISTA ANALÍTICA PARA DASHBOARDS Y REPORTES (.NET MAUI & POWER BI)
-- =============================================================================
-- Esta vista une las tablas mediante INNER JOIN y calcula en tiempo real:
-- 1. ValorInventario = Precio * Stock
-- 2. EstadoStock = Alerta semafórica ('Agotado', 'Stock Bajo', 'Óptimo')
CREATE OR ALTER VIEW vw_ReporteInventario
AS
SELECT
    P.ProductoID,
    P.CodigoBarras,
    P.Nombre AS Producto,
    C.CategoriaID,
    C.Nombre AS Categoria,
    P.Precio,
    P.Stock,
    CAST((P.Precio * P.Stock) AS DECIMAL(18,2)) AS ValorInventario,
    CASE
        WHEN P.Stock = 0 THEN 'Agotado'
        WHEN P.Stock <= 5 THEN 'Stock Bajo'
        ELSE 'Óptimo'
    END AS EstadoStock,
    C.Descripcion AS DescripcionCategoria
FROM Productos P
INNER JOIN Categorias C
    ON P.CategoriaID = C.CategoriaID;
GO

PRINT 'Vista vw_ReporteInventario compilada con éxito.';

⚠️ REGLA CRÍTICA DE COMUNICACIÓN EN ANDROID (LEER OBLIGATORIAMENTE):

A partir de Android 9.0 (API 28), el sistema operativo bloquea por defecto todo el tráfico de red en texto plano (sin cifrar). Como las conexiones directas a SQL Server por TCP/IP en el puerto 1433 no utilizan certificados SSL/TLS en entornos locales de desarrollo, Android rechazará la conexión con un error silencioso de SocketException: Connection refused / Timeout.

Para permitir que tu aplicación se conecte con la IP de SQL Server, es 100% indispensable activar el atributo android:usesCleartextTraffic="true" dentro de la etiqueta <application> y declarar los permisos de red antes de ella.

  1. Paso A (Localizar el archivo): En Visual Studio, ve a la ventana del Explorador de soluciones (Solution Explorer) a la derecha. Despliega la carpeta Platforms haciendo clic en su flechita, luego despliega la subcarpeta Android.
  2. Paso B (Abrir el editor): Haz doble clic sobre AndroidManifest.xml (o haz clic derecho → Ver código / View Code).
  3. Paso C (Estructura de Permisos): Coloca los permisos INTERNET y ACCESS_NETWORK_STATE como hijos directos de <manifest>, justo arriba de <application>.
  4. Paso D (Habilitar Cleartext): Asegúrate de que dentro de la etiqueta <application> esté escrito el atributo:
    android:usesCleartextTraffic="true"

using Microsoft.Data.SqlClient;
using System.Collections.ObjectModel;
using System.Data;

namespace InventarioMauiApp2;

/// <summary>
/// Página principal de la aplicación encargada de gestionar el CRUD de productos,
/// la carga de categorías, el filtrado dinámico y la navegación hacia el Dashboard.
/// </summary>
public partial class MainPage : ContentPage
{
    // =========================================================================
    // CONSTANTES DE CONFIGURACIÓN PARA CONEXIÓN A SQL SERVER
    // =========================================================================
    private const string SqlUser = "JUANCITO";
    private const string SqlPass = "123456";
    private const string SqlDb = "InventarioDB1";
    private const int SqlPort = 1433;

    // =========================================================================
    // COLECCIONES DE DATOS Y VARIABLES DE ESTADO
    // =========================================================================

    public ObservableCollection<CategoriaModel> Categorias { get; set; } = new();
    private readonly List<ProductoModel> _todosLosProductos = new();
    public ObservableCollection<ProductoModel> ProductosFiltrados { get; set; } = new();
    private int _productoEnEdicionId = 0;

    public MainPage()
    {
        InitializeComponent();

        // Enlace de datos (Data Binding) directo hacia los controles de la UI
        PickerCategorias.ItemsSource = Categorias;
        CvProductos.ItemsSource = ProductosFiltrados;
    }

    // =========================================================================
    // CONEXIÓN Y CARGA INICIAL
    // =========================================================================

    private string ObtenerCadenaConexion()
    {
        string ip = TxtServerIp.Text?.Trim() ?? "10.0.0.15";
        return $"Server={ip},{SqlPort};Database={SqlDb};User Id={SqlUser};Password={SqlPass};TrustServerCertificate=True;Encrypt=False;Connect Timeout=5;";
    }

    private async void OnProbarConexionClicked(object? sender, EventArgs e)
    {
        await CargarDatosIniciales();
    }

    private async Task CargarDatosIniciales()
    {
        try
        {
            await CargarCategorias();
            await CargarProductos();
            await DisplayAlertAsync("✅ Conexión Exitosa", "Base de datos conectada correctamente.", "Aceptar");
        }
        catch (Exception ex)
        {
            await DisplayAlertAsync("❌ Error de Conexión", $"No se pudo conectar al servidor:\n{ex.Message}", "OK");
        }
    }

    // =========================================================================
    // OPERACIONES DE LECTURA (READ) Y BÚSQUEDA EN MEMORIA
    // =========================================================================

    private async Task CargarCategorias()
    {
        Categorias.Clear();

        using SqlConnection conn = new(ObtenerCadenaConexion());
        await conn.OpenAsync();

        string query = "SELECT CategoriaID, Nombre, Descripcion FROM Categorias ORDER BY Nombre ASC";
        using SqlCommand cmd = new(query, conn);
        using SqlDataReader reader = await cmd.ExecuteReaderAsync();

        while (await reader.ReadAsync())
        {
            Categorias.Add(new CategoriaModel
            {
                CategoriaID = reader.GetInt32(0),
                Nombre = reader.GetString(1),
                Descripcion = reader.IsDBNull(2) ? "" : reader.GetString(2)
            });
        }
    }

    private async Task CargarProductos()
    {
        _todosLosProductos.Clear();

        using SqlConnection conn = new(ObtenerCadenaConexion());
        await conn.OpenAsync();

        string query = @"
            SELECT p.ProductoID, p.CategoriaID, p.CodigoBarras, p.Nombre, p.Precio, p.Stock, c.Nombre AS CategoriaNombre 
            FROM Productos p
            INNER JOIN Categorias c ON p.CategoriaID = c.CategoriaID
            ORDER BY p.ProductoID DESC";

        using SqlCommand cmd = new(query, conn);
        using SqlDataReader reader = await cmd.ExecuteReaderAsync();

        while (await reader.ReadAsync())
        {
            _todosLosProductos.Add(new ProductoModel
            {
                ProductoID = reader.GetInt32(0),
                CategoriaID = reader.GetInt32(1),
                CodigoBarras = reader.GetString(2),
                Nombre = reader.GetString(3),
                Precio = reader.GetDecimal(4),
                Stock = reader.GetInt32(5),
                CategoriaNombre = reader.GetString(6)
            });
        }

        FiltrarCatalogo(TxtBuscarGlobal?.Text);
    }

    private void OnBuscarGlobalTextChanged(object? sender, TextChangedEventArgs e)
    {
        FiltrarCatalogo(e.NewTextValue);
    }

    private void FiltrarCatalogo(string? filtro)
    {
        string criterio = (filtro ?? "").Trim().ToLower();

        var coincidentes = string.IsNullOrWhiteSpace(criterio)
            ? _todosLosProductos
            : _todosLosProductos.Where(p =>
                p.Nombre.ToLower().Contains(criterio) ||
                p.CodigoBarras.ToLower().Contains(criterio) ||
                p.CategoriaNombre.ToLower().Contains(criterio) ||
                p.CategoriaID.ToString() == criterio
            ).ToList();

        ProductosFiltrados.Clear();
        foreach (var prod in coincidentes)
        {
            ProductosFiltrados.Add(prod);
        }
    }

    // =========================================================================
    // VALIDACIONES Y OPERACIONES DE ESCRITURA (CREATE / UPDATE)
    // =========================================================================

    private async Task<bool> ExisteCodigoBarrasAsync(string codigo, int idActual, SqlConnection conn)
    {
        string query = "SELECT COUNT(1) FROM Productos WHERE CodigoBarras = @CodigoBarras AND ProductoID != @ProductoID";
        using SqlCommand cmd = new(query, conn);

        cmd.Parameters.AddWithValue("@CodigoBarras", codigo);
        cmd.Parameters.AddWithValue("@ProductoID", idActual);

        int count = Convert.ToInt32(await cmd.ExecuteScalarAsync());
        return count > 0;
    }

    private async void OnGuardarClicked(object? sender, EventArgs e)
    {
        if (PickerCategorias.SelectedItem is not CategoriaModel catSeleccionada)
        {
            await DisplayAlertAsync("⚠️ Validación", "Debe seleccionar una categoría para el producto.", "Entendido");
            return;
        }

        string codigo = TxtCodigoBarras.Text?.Trim() ?? "";
        string nombre = TxtNombre.Text?.Trim() ?? "";

        if (string.IsNullOrWhiteSpace(codigo))
        {
            await DisplayAlertAsync("⚠️ Campo Requerido", "El código de barras no puede estar vacío.", "Entendido");
            return;
        }

        if (string.IsNullOrWhiteSpace(nombre))
        {
            await DisplayAlertAsync("⚠️ Campo Requerido", "El nombre del producto es obligatorio.", "Entendido");
            return;
        }

        if (!decimal.TryParse(TxtPrecio.Text, out decimal precio) || precio < 0)
        {
            await DisplayAlertAsync("⚠️ Valor Inválido", "Ingrese un precio numérico válido mayor o igual a 0.", "Entendido");
            return;
        }

        if (!int.TryParse(TxtStock.Text, out int stock) || stock < 0)
        {
            await DisplayAlertAsync("⚠️ Valor Inválido", "Ingrese una cantidad de stock entera y positiva.", "Entendido");
            return;
        }

        try
        {
            using SqlConnection conn = new(ObtenerCadenaConexion());
            await conn.OpenAsync();

            if (await ExisteCodigoBarrasAsync(codigo, _productoEnEdicionId, conn))
            {
                await DisplayAlertAsync("⚠️ Código Duplicado", $"El código '{codigo}' ya pertenece a otro producto registrado.", "Aceptar");
                return;
            }

            if (_productoEnEdicionId == 0)
            {
                string insertSql = @"
                    INSERT INTO Productos (CategoriaID, CodigoBarras, Nombre, Precio, Stock)
                    VALUES (@CategoriaID, @CodigoBarras, @Nombre, @Precio, @Stock)";

                using SqlCommand cmd = new(insertSql, conn);
                cmd.Parameters.AddWithValue("@CategoriaID", catSeleccionada.CategoriaID);
                cmd.Parameters.AddWithValue("@CodigoBarras", codigo);
                cmd.Parameters.AddWithValue("@Nombre", nombre);
                cmd.Parameters.AddWithValue("@Precio", precio);
                cmd.Parameters.AddWithValue("@Stock", stock);

                await cmd.ExecuteNonQueryAsync();
                await DisplayAlertAsync("✅ Inserción Exitosa", $"El producto '{nombre}' se registró correctamente.", "Aceptar");
            }

using Microsoft.Data.SqlClient;
using System.Collections.ObjectModel;

namespace InventarioMauiApp2;

/// <summary>
/// Página de Dashboard Analítico que consulta la vista oficial 'vw_ReporteInventario'
/// en SQL Server, ordenando los productos de MAYOR a MENOR existencia con semáforo
/// de colores (Verde = Óptimo, Amarillo = Stock Bajo, Rojo = Agotado).
/// </summary>
public partial class ReportePage : ContentPage
{
    private const string SqlUser = "JUANCITO";
    private const string SqlPass = "123456";
    private const string SqlDb = "InventarioDB1";
    private const int SqlPort = 1433;
    private readonly string _serverIp;

    public ObservableCollection<CategoriaResumenModel> ResumenCategorias { get; set; } = new();
    public ObservableCollection<ReporteProductoItem> ProductosReporte { get; set; } = new();

    public ReportePage(string serverIp)
    {
        InitializeComponent();
        _serverIp = string.IsNullOrWhiteSpace(serverIp) ? "10.0.0.15" : serverIp;
        LblServidorActivo.Text = $"Servidor: {_serverIp}";

        CvCategoriasResumen.ItemsSource = ResumenCategorias;
        CvReporteProductos.ItemsSource = ProductosReporte;
    }

    protected override async void OnAppearing()
    {
        base.OnAppearing();
        await CargarDashboardAsync();
    }

    private string ObtenerCadenaConexion()
    {
        return $"Server={_serverIp},{SqlPort};Database={SqlDb};User Id={SqlUser};Password={SqlPass};TrustServerCertificate=True;Encrypt=False;Connect Timeout=5;";
    }

    private async void OnActualizarReporteClicked(object? sender, EventArgs e)
    {
        await CargarDashboardAsync();
    }

    private async Task CargarDashboardAsync()
    {
        try
        {
            var listaTemporal = new List<ReporteProductoItem>();

            using SqlConnection conn = new(ObtenerCadenaConexion());
            await conn.OpenAsync();

            // Consulta directa sobre la vista analítica 'vw_ReporteInventario'
            // ORDENADA ESTRICTAMENTE DE MAYOR A MENOR EXISTENCIA (Stock DESC)
            string query = @"
                SELECT ProductoID, CodigoBarras, Producto, CategoriaID, Categoria, 
                       Precio, Stock, ValorInventario, EstadoStock
                FROM vw_ReporteInventario
                ORDER BY Stock DESC, ValorInventario DESC;";

            using SqlCommand cmd = new(query, conn);
            using SqlDataReader reader = await cmd.ExecuteReaderAsync();

            while (await reader.ReadAsync())
            {
                listaTemporal.Add(new ReporteProductoItem
                {
                    ProductoID = reader.GetInt32(0),
                    CodigoBarras = reader.GetString(1),
                    Nombre = reader.GetString(2),
                    CategoriaID = reader.GetInt32(3),
                    CategoriaNombre = reader.GetString(4),
                    Precio = reader.GetDecimal(5),
                    Stock = reader.GetInt32(6),
                    ValorTotal = reader.GetDecimal(7),
                    EstadoStock = reader.GetString(8)
                });
            }

            // 1. Cálculo de KPIs globales
            decimal valorTotalInventario = listaTemporal.Sum(x => x.ValorTotal);
            int totalUnidades = listaTemporal.Sum(x => x.Stock);
            int totalProductos = listaTemporal.Count;
            int productosCriticos = listaTemporal.Count(x => x.Stock <= 5);

            LblValorTotal.Text = $"RD$ {valorTotalInventario:N2}";
            LblTotalUnidades.Text = $"{totalUnidades:N0} uds";
            LblTotalProductos.Text = totalProductos.ToString();
            LblStockBajo.Text = $"{productosCriticos} críticos";

            // 2. Agrupación para el gráfico de barras por Categoría
            ResumenCategorias.Clear();
            var grupos = listaTemporal
                .GroupBy(p => p.CategoriaNombre)
                .Select(g => new
                {
                    Categoria = g.Key,
                    Valor = g.Sum(x => x.ValorTotal),
                    Unidades = g.Sum(x => x.Stock),
                    CantidadProductos = g.Count()
                })
                .OrderByDescending(x => x.Valor)
                .ToList();

            foreach (var g in grupos)
            {
                double pct = valorTotalInventario > 0 ? (double)(g.Valor / valorTotalInventario) : 0;
                ResumenCategorias.Add(new CategoriaResumenModel
                {
                    CategoriaNombre = g.Categoria,
                    ValorTotal = g.Valor,
                    Porcentaje = pct,
                    ValorFormateado = $"RD$ {g.Valor:N2} ({pct:P0})",
                    DetalleItems = $"{g.CantidadProductos} productos • {g.Unidades} unidades en stock"
                });
            }

            // 3. Poblar la lista detallada (ya ordenada de mayor a menor)
            ProductosReporte.Clear();
            foreach (var item in listaTemporal)
            {
                ProductosReporte.Add(item);
            }
        }
        catch (Exception ex)
        {
            await DisplayAlertAsync("❌ Error al generar reporte", @$"Verifica la conexión con {_serverIp}: " + ex.Message, "OK");
        }
    }
