01. INICIALIZACIÓN DEL PROYECTO

El proyecto debe inicializarse utilizando la plantilla oficial de .NET MAUI en Visual Studio 2026 o a través de la interfaz de comandos CLI de .NET. Esta plantilla configura los destinos multiplataforma (Android, Windows, iOS, MacCatalyst) bajo un único proyecto unificado.

  • Nombre Oficial del Proyecto: InventarioMauiApp1
  • Target Framework Requerido: net8.0 o net9.0
  • Comando CLI de Creación:
Terminal / PowerShell 
dotnet new maui -n InventarioMauiApp1
cd InventarioMauiApp1
02. INSTALACIÓN DE LIBRERÍAS Y PERMISOS

Para comunicar la aplicación cliente directamente con el motor Microsoft SQL Server en el puerto 1433 se requiere el paquete oficial Microsoft.Data.SqlClient. Además, en plataformas como Android, el sistema operativo bloquea por defecto las conexiones de red salientes y el tráfico sin cifrado TLS estricto si no se definen explícitamente en el manifiesto.

Instalación del controlador NuGet:

Package Manager Console / Terminal 
dotnet add package Microsoft.Data.SqlClient

Permisos de red en Platforms/Android/AndroidManifest.xml:

AndroidManifest.xml 
<uses-permission android:name="android.permission.INTERNET" />
<application android:usesCleartextTraffic="true" ...>
03. SCRIPT SQL SERVER (BASE DE DATOS Y TABLAS)

¿Qué hace este script?
1. Crea la base de datos InventarioDB1 y se posiciona en ella.
2. Define la tabla padre Categorias con clave primaria IDENTITY(1,1).
3. Define la tabla relacionada Productos vinculada mediante la clave foránea FK_Productos_Categorias con eliminación en cascada (ON DELETE CASCADE) y una restricción única UNIQUE en CodigoBarras.
4. Puebla datos maestros de categorías y productos iniciales.
5. Crea la vista analítica vw_ReporteInventario con cálculo en línea del valor total del stock y un semáforo condicional de existencias.

SQL Server Management Studio (T-SQL) 
IF NOT EXISTS (SELECT name FROM sys.databases WHERE name = N'InventarioDB1')
BEGIN
    CREATE DATABASE InventarioDB1;
END
GO

USE InventarioDB1;
GO

-- 1. Tabla Principal
CREATE TABLE Categorias (
    CategoriaID INT IDENTITY(1,1) PRIMARY KEY,
    Nombre NVARCHAR(100) NOT NULL,
    Descripcion NVARCHAR(250) NULL
);
GO

-- 2. Tabla Relacionada (CRUD objetivo)
CREATE TABLE Productos (
    ProductoID INT IDENTITY(1,1) PRIMARY KEY,
    CategoriaID INT NOT NULL,
    CodigoBarras NVARCHAR(50) NOT NULL UNIQUE,
    Nombre NVARCHAR(120) NOT NULL,
    Precio DECIMAL(18,2) NOT NULL DEFAULT 0.00,
    Stock INT NOT NULL DEFAULT 0,
    CONSTRAINT FK_Productos_Categorias FOREIGN KEY (CategoriaID)
        REFERENCES Categorias(CategoriaID) ON DELETE CASCADE
);
GO

-- VISTA DE REPORTE DE INVENTARIO
CREATE VIEW vw_ReporteInventario
AS
SELECT
    P.ProductoID,
    P.CodigoBarras,
    P.Nombre AS Producto,
    C.CategoriaID,
    C.Nombre AS Categoria,
    P.Precio,
    P.Stock,
    (P.Precio * P.Stock) AS ValorInventario,
    CASE
        WHEN P.Stock = 0 THEN 'Agotado'
        WHEN P.Stock <= 20 THEN 'Stock Bajo'
        WHEN P.Stock <= 50 THEN 'Stock Medio'
        ELSE 'Stock Disponible'
    END AS EstadoStock,
    C.Descripcion AS DescripcionCategoria
FROM Productos P
INNER JOIN Categorias C
    ON P.CategoriaID = C.CategoriaID;
GO

SELECT * FROM vw_ReporteInventario;

05. MAINPAGE.XAML.CS (LÓGICA C# Y ADO.NET)

¿Qué hace este código C#?
1. Utiliza el método nativo DisplayAlertAsync requerido por las versiones recientes de MAUI para suprimir los avisos de obsolescencia CS0618.
2. Incluye firmas con nulabilidad explícita (object? sender) suprimiendo los avisos del compilador CS8622.
3. Previene colisiones de clave única: ejecuta el método auxiliar ExisteCodigoBarrasAsync antes de guardar, informando al usuario de forma amigable si el código de barras ya existe en otro registro sin lanzar excepciones SQL no controladas.
4. Filtro unificado en memoria: el método FiltrarCatalogo evalúa si el texto ingresado coincide con el nombre del producto, el código de barras, el nombre de la categoría o el identificador numérico de la categoría.
5. Maneja la alternancia entre inserción (INSERT) y actualización (UPDATE) según el valor de _productoEnEdicionId.

MainPage.xaml.cs 
using Microsoft.Data.SqlClient;
using System.Collections.ObjectModel;
using System.Data;

namespace InventarioMauiApp1;

public partial class MainPage : ContentPage
{
    private const string SqlUser = "JUANCITO";
    private const string SqlPass = "123456";
    private const string SqlDb = "InventarioDB1";
    private const int SqlPort = 1433;

    public ObservableCollection Categorias { get; set; } = new();
    
    // Lista completa en memoria
    private readonly List _todosLosProductos = new();
    
    // Lista enlazada a la vista
    public ObservableCollection ProductosFiltrados { get; set; } = new();

    private int _productoEnEdicionId = 0;

    public MainPage()
    {
        InitializeComponent();
        PickerCategorias.ItemsSource = Categorias;
        CvProductos.ItemsSource = ProductosFiltrados;
    }

    private string ObtenerCadenaConexion()
    {
        string ip = TxtServerIp.Text?.Trim() ?? "10.0.0.15";
        return $"Server={ip},{SqlPort};Database={SqlDb};User Id={SqlUser};Password={SqlPass};TrustServerCertificate=True;Encrypt=False;Connect Timeout=5;";
    }

    private async void OnProbarConexionClicked(object? sender, EventArgs e)
    {
        await CargarDatosIniciales();
    }

    private async Task CargarDatosIniciales()
    {
        try
        {
            await CargarCategorias();
            await CargarProductos();
            await DisplayAlertAsync("✅ Conexión Exitosa", "Base de datos conectada correctamente.", "Aceptar");
        }
        catch (Exception ex)
        {
            await DisplayAlertAsync("❌ Error de Conexión", $"No se pudo conectar al servidor:\n{ex.Message}", "OK");
        }
    }

    // READ: Categorías
    private async Task CargarCategorias()
    {
        Categorias.Clear();

        using SqlConnection conn = new(ObtenerCadenaConexion());
        await conn.OpenAsync();

        string query = "SELECT CategoriaID, Nombre, Descripcion FROM Categorias ORDER BY Nombre ASC";
        using SqlCommand cmd = new(query, conn);
        using SqlDataReader reader = await cmd.ExecuteReaderAsync();

        while (await reader.ReadAsync())
        {
            Categorias.Add(new CategoriaModel
            {
                CategoriaID = reader.GetInt32(0),
                Nombre = reader.GetString(1),
                Descripcion = reader.IsDBNull(2) ? "" : reader.GetString(2)
            });
        }
    }

    // READ: Productos (INNER JOIN)
    private async Task CargarProductos()
    {
        _todosLosProductos.Clear();
        using SqlConnection conn = new(ObtenerCadenaConexion());
        await conn.OpenAsync();

        string query = @"
            SELECT p.ProductoID, p.CategoriaID, p.CodigoBarras, p.Nombre, p.Precio, p.Stock, c.Nombre AS CategoriaNombre 
            FROM Productos p
            INNER JOIN Categorias c ON p.CategoriaID = c.CategoriaID
            ORDER BY p.ProductoID DESC";

        using SqlCommand cmd = new(query, conn);
        using SqlDataReader reader = await cmd.ExecuteReaderAsync();

        while (await reader.ReadAsync())
        {
            _todosLosProductos.Add(new ProductoModel
            {
                ProductoID = reader.GetInt32(0),
                CategoriaID = reader.GetInt32(1),
                CodigoBarras = reader.GetString(2),
                Nombre = reader.GetString(3),
                Precio = reader.GetDecimal(4),
                Stock = reader.GetInt32(5),
                CategoriaNombre = reader.GetString(6)
            });
        }

        FiltrarCatalogo(TxtBuscarGlobal?.Text);
    }

    // BÚSQUEDA DINÁMICA UNIFICADA: Producto, Código, Categoría o ID Categoría
    private void OnBuscarGlobalTextChanged(object? sender, TextChangedEventArgs e)
    {
        FiltrarCatalogo(e.NewTextValue);
    }

    private void FiltrarCatalogo(string? filtro)
    {
        string criterio = (filtro ?? "").Trim().ToLower();

        var coincidentes = string.IsNullOrWhiteSpace(criterio)
            ? _todosLosProductos
            : _todosLosProductos.Where(p =>
                p.Nombre.ToLower().Contains(criterio) ||
                p.CodigoBarras.ToLower().Contains(criterio) ||
                p.CategoriaNombre.ToLower().Contains(criterio) ||
                p.CategoriaID.ToString() == criterio
            ).ToList();

        ProductosFiltrados.Clear();
        foreach (var prod in coincidentes)
        {
            ProductosFiltrados.Add(prod);
        }
    }

    // VALIDACIÓN PREVIA DE CÓDIGO DE BARRAS DUPLICADO
    private async Task ExisteCodigoBarrasAsync(string codigo, int idActual, SqlConnection conn)
    {
        string query = "SELECT COUNT(1) FROM Productos WHERE CodigoBarras = @CodigoBarras AND ProductoID != @ProductoID";
        using SqlCommand cmd = new(query, conn);
        cmd.Parameters.AddWithValue("@CodigoBarras", codigo);
        cmd.Parameters.AddWithValue("@ProductoID", idActual);

        int count = Convert.ToInt32(await cmd.ExecuteScalarAsync());
        return count > 0;
    }

    // CREATE / UPDATE
    private async void OnGuardarClicked(object? sender, EventArgs e)
    {
        if (PickerCategorias.SelectedItem is not CategoriaModel catSeleccionada)
        {
            await DisplayAlertAsync("⚠️ Validación", "Debe seleccionar una categoría para el producto.", "Entendido");
            return;
        }

        string codigo = TxtCodigoBarras.Text?.Trim() ?? "";
        string nombre = TxtNombre.Text?.Trim() ?? "";

        if (string.IsNullOrWhiteSpace(codigo))
        {
            await DisplayAlertAsync("⚠️ Campo Requerido", "El código de barras no puede estar vacío.", "Entendido");
            return;
        }

        if (string.IsNullOrWhiteSpace(nombre))
        {
            await DisplayAlertAsync("⚠️ Campo Requerido", "El nombre del producto es obligatorio.", "Entendido");
            return;
        }

        if (!decimal.TryParse(TxtPrecio.Text, out decimal precio) || precio < 0)
        {
            await DisplayAlertAsync("⚠️ Valor Inválido", "Ingrese un precio numérico válido mayor o igual a 0.", "Entendido");
            return;
        }

        if (!int.TryParse(TxtStock.Text, out int stock) || stock < 0)
        {
            await DisplayAlertAsync("⚠️ Valor Inválido", "Ingrese una cantidad de stock entera y positiva.", "Entendido");
            return;
        }

        try
        {
            using SqlConnection conn = new(ObtenerCadenaConexion());
            await conn.OpenAsync();

            // Verificación previa de duplicados
            if (await ExisteCodigoBarrasAsync(codigo, _productoEnEdicionId, conn))
            {
                await DisplayAlertAsync("⚠️ Código Duplicado", $"El código '{codigo}' ya pertenece a otro producto registrado.", "Aceptar");
                return;
            }

            if (_productoEnEdicionId == 0)
            {
                // INSERT
                string insertSql = @"
                    INSERT INTO Productos (CategoriaID, CodigoBarras, Nombre, Precio, Stock)
                    VALUES (@CategoriaID, @CodigoBarras, @Nombre, @Precio, @Stock)";

                using SqlCommand cmd = new(insertSql, conn);
                cmd.Parameters.AddWithValue("@CategoriaID", catSeleccionada.CategoriaID);
                cmd.Parameters.AddWithValue("@CodigoBarras", codigo);
                cmd.Parameters.AddWithValue("@Nombre", nombre);
                cmd.Parameters.AddWithValue("@Precio", precio);
                cmd.Parameters.AddWithValue("@Stock", stock);

                await cmd.ExecuteNonQueryAsync();
                await DisplayAlertAsync("✅ Inserción Exitosa", $"El producto '{nombre}' se registró correctamente.", "Aceptar");
            }
            else
            {
                // UPDATE
                string updateSql = @"
                    UPDATE Productos 
                    SET CategoriaID = @CategoriaID, CodigoBarras = @CodigoBarras, Nombre = @Nombre, Precio = @Precio, Stock = @Stock
                    WHERE ProductoID = @ProductoID";

                using SqlCommand cmd = new(updateSql, conn);
                cmd.Parameters.AddWithValue("@CategoriaID", catSeleccionada.CategoriaID);
                cmd.Parameters.AddWithValue("@CodigoBarras", codigo);
                cmd.Parameters.AddWithValue("@Nombre", nombre);
                cmd.Parameters.AddWithValue("@Precio", precio);
                cmd.Parameters.AddWithValue("@Stock", stock);
                cmd.Parameters.AddWithValue("@ProductoID", _productoEnEdicionId);

                await cmd.ExecuteNonQueryAsync();
                await DisplayAlertAsync("✅ Actualización Exitosa", $"El producto #{_productoEnEdicionId} fue actualizado.", "Aceptar");
            }

            LimpiarFormulario();
            await CargarProductos();
        }
        catch (Exception ex)
        {
            await DisplayAlertAsync("❌ Error SQL", ex.Message, "OK");
        }
    }

    // PREPARAR EDICIÓN
    private void OnEditarClicked(object? sender, EventArgs e)
    {
        if (sender is Button btn && btn.CommandParameter is ProductoModel prod)
        {
            _productoEnEdicionId = prod.ProductoID;
            TxtCodigoBarras.Text = prod.CodigoBarras;
            TxtNombre.Text = prod.Nombre;
            TxtPrecio.Text = prod.Precio.ToString("0.00");
            TxtStock.Text = prod.Stock.ToString();

            PickerCategorias.SelectedItem = Categorias.FirstOrDefault(c => c.CategoriaID == prod.CategoriaID);

            LblModoFormulario.Text = $"✏️ Editando Producto #{prod.ProductoID}";
            LblModoFormulario.TextColor = Color.FromArgb("#F59E0B");
            BtnGuardar.Text = "Actualizar Cambios";
            BtnGuardar.BackgroundColor = Color.FromArgb("#F59E0B");
        }
    }

    // DELETE
    private async void OnEliminarClicked(object? sender, EventArgs e)
    {
        if (sender is Button btn && btn.CommandParameter is int productoId)
        {
            var item = _todosLosProductos.FirstOrDefault(p => p.ProductoID == productoId);
            string nombreItem = item?.Nombre ?? $"ID {productoId}";

            bool confirmar = await DisplayAlertAsync(
                "🗑️ Confirmar Eliminación", 
                $"¿Seguro que deseas eliminar '{nombreItem}' del inventario?\nEsta acción no se puede deshacer.", 
                "Sí, Eliminar", 
                "Cancelar");

            if (!confirmar) return;

            try
            {
                using SqlConnection conn = new(ObtenerCadenaConexion());
                await conn.OpenAsync();

                string deleteSql = "DELETE FROM Productos WHERE ProductoID = @ProductoID";
                using SqlCommand cmd = new(deleteSql, conn);
                cmd.Parameters.AddWithValue("@ProductoID", productoId);

                await cmd.ExecuteNonQueryAsync();

                await DisplayAlertAsync("✅ Eliminado", $"El producto '{nombreItem}' ha sido removido.", "Aceptar");

                if (_productoEnEdicionId == productoId)
                {
                    LimpiarFormulario();
                }

                await CargarProductos();
            }
            catch (Exception ex)
            {
                await DisplayAlertAsync("❌ Error al Eliminar", ex.Message, "OK");
            }
        }
    }

    private void OnLimpiarClicked(object? sender, EventArgs e)
    {
        LimpiarFormulario();
    }

    private void LimpiarFormulario()
    {
        _productoEnEdicionId = 0;
        TxtCodigoBarras.Text = string.Empty;
        TxtNombre.Text = string.Empty;
        TxtPrecio.Text = string.Empty;
        TxtStock.Text = string.Empty;
        PickerCategorias.SelectedItem = null;

        LblModoFormulario.Text = "Nuevo Producto";
        LblModoFormulario.TextColor = Color.FromArgb("#94A3B8");
        BtnGuardar.Text = "Guardar";
        BtnGuardar.BackgroundColor = Color.FromArgb("#10B981");
    }
